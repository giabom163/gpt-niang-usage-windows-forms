# Windows 公开版素材

此发行附带自绘简版五档 PNG 与合成提示音，可以直接安装。公开版的图像和声音由本项目生成，允许随本项目分发。演示视频使用的素材单独保留。

从 gpt-niang-usage 目录计算，文件为：
assets/gpt-dragon-niang-bust.png
assets/forms/low.png
assets/forms/medium.png
assets/forms/high.png
assets/forms/xhigh.png
assets/forms/max.png
assets/press.wav
assets/release.wav

可用自己有权使用的透明 PNG 或 WAV 覆盖对应文件。五个立绘分别对应轻度、中度、高、极高和 Ultra。半身图用于纯 Q 模式和插件图标。
